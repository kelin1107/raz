🐾 第 1 周 · 生命世界

动物与植物是低龄孩子最可能主动观察的对象。这一周把动物园、农场、昆虫、植物都变成「活教材」，用五感去碰真实世界，再回到书里巩固动物名称和简单句型。

Day 1The ZooNF 科普aa · 动物认知
📖 今日书AA60 The Zoo（Level aa，句式：动物认知）
🌿 活动去动物园/看动物绘本，玩「动物模仿秀」(学动物走/叫)；在家用动物玩偶排一排。
🔤 语言点动物名称词 zoo / lion / monkey / elephant，+ 句型「I see a ___.」
✏️ 画+话认字画一种最喜欢的动物园动物，标英文名，做「我的动物园单词卡」。
Day 2The Big CatNF 科普A · 动物认知
📖 今日书A03 The Big Cat（Level A，句式：动物认知）
🌿 活动对比大猫(狮/虎)和小猫，找毛茸茸的图或视频；用纸箱做一只「猫窝」。
🔤 语言点大小对比 big / little，猫科词 cat / lion / tiger。
✏️ 画+话认字画一只大猫，写「Big cat」。
Day 3This InsectNF 科普A · This句式
📖 今日书A26 This Insect（Level A，句式：This句式）
🌿 活动小区/公园「昆虫探索」，用放大镜看蚂蚁、瓢虫——只观察不抓。
🔤 语言点句型「This is a ___.」(This is an insect.)，词 insect / bug。
✏️ 画+话认字画一只小虫，配「This is a bug.」
Day 4The PlantNF 科普aa · 综合
📖 今日书AA14 The Plant（Level aa，句式：综合）
🌿 活动种一颗绿豆在湿棉花里，每天观察记录；或去菜园看真植物。
🔤 语言点植物词 plant / leaf / flower / root，+ 「I see ___.」
✏️ 画+话认字画发芽的植物，标 root / leaf / flower。
Day 5What Lives Here?NF 科普A · What句式
📖 今日书A06 What Lives Here?（Level A，句式：What句式）
🌿 活动聊「谁住在这里」——树洞 / 洞穴 / 鸟窝；用积木搭一个「家」给小动物。
🔤 语言点提问「What lives here?」，栖息地词 tree / cave / nest。
✏️ 画+话认字画一个动物的家，写「Home」。

🌍 第 2 周 · 地球与宇宙

天气、季节、水——都是出门就能感知的科普。这一周用玩水盆、捡落叶、做天气表，把抽象的自然现象变成孩子手里的材料。

Day 1WaterNF 科普aa · 天气水句式
📖 今日书AA08 Water（Level aa，句式：天气水句式）
🌿 活动玩水感官盆(杯子/漏斗/海绵)，感受水的流动；聊「水在哪里」。
🔤 语言点water / rain / river / ocean，+ 「I see water.」
✏️ 画+话认字画一片水(河/海)，标 water。
Day 2SpringNF 科普aa · 季节句式
📖 今日书AA09 Spring（Level aa，句式：季节句式）
🌿 活动春游找新芽、花；用捡来的花瓣树叶做拼贴画。
🔤 语言点spring / warm / flower / green。
✏️ 画+话认字画春天，写「Spring」。
Day 3WinterNF 科普aa · 季节句式
📖 今日书AA12 Winter（Level aa，句式：季节句式）
🌿 活动聊冬天(冷/雪/穿厚)，没有雪就用蓝白手工做「雪人」。
🔤 语言点winter / cold / snow / white。
✏️ 画+话认字画雪人，标 snow。
Day 4Spring WeatherNF 科普A · 天气水句式
📖 今日书A12 Spring Weather（Level A，句式：天气水句式）
🌿 活动做「一周天气表」，每天画晴/雨/云；对应书里春雨。
🔤 语言点rain / cloud / wind / sun，+ 「It is ___.」
✏️ 画+话认字画今天的天气，写天气词。
Day 5The OceanNF 科普aa · 天气水句式
📖 今日书AA13 The Ocean（Level aa，句式：天气水句式）
🌿 活动海边/湖边捡石头贝壳(或水盆+蓝布模拟)，聊海洋动物。
🔤 语言点ocean / fish / wave / shell。
✏️ 画+话认字画大海，标 ocean。
📚 本族延伸阅读（9 本，从总表挑）： A17 Spring and Fall、A18 The Rainstorm、AA07 The Coast、AA10 Summer、AA11 It Is Fall、AA63 Summer Camp、AA64 Summer Picnics、AA65 The Post Office、AA69 At the Lake
⚡ 第 3 周 · 物质与能量

提醒：aa+A 级里「物质与能量」主题的 NF 书只有 3 本(都是交通工具/力)，科普密度偏低。这一周用 3 本核心书打底，再加 2 个动手实验日(沉浮、磁铁)补上「做科学」的体验——正好对应你说的「科普词汇最稳扎稳打」。

Day 1Move It!NF 科普A · 综合
📖 今日书A46 Move It!（Level A，句式：综合）
🌿 活动推/拉小车、滚球，感受「动起来」；聊什么让东西动。
🔤 语言点move / push / pull / roll。
✏️ 画+话认字画一辆会动的小车，写「Move it!」
Day 2Car PartsNF 科普A · 综合
📖 今日书A37 Car Parts（Level A，句式：综合）
🌿 活动玩玩具车，指认轮子/门/窗；用纸盒做一辆「车」贴轮子。
🔤 语言点wheel / door / window / car。
✏️ 画+话认字画车，标 wheel / door。
Day 3Going PlacesNF 科普A · 综合
📖 今日书A29 Going Places（Level A，句式：综合）
🌿 活动聊怎么去不同地方(走/车/公交)；用积木搭「路」和「站」。
🔤 语言点go / car / bus / walk，+ 「We go ___.」
✏️ 画+话认字画一种交通工具，写它的名。
Day 4🔬 实验日 · 沉与浮动手实验
🌿 活动碗里装水，放积木/石头/塑料玩具，先猜沉/浮再试。
🔤 语言点float / sink / heavy / light。
✏️ 画+话认字画「浮起来」和「沉下去」两样东西。
Day 5🔬 实验日 · 磁铁寻宝动手实验
🌿 活动用磁铁吸硬币/回形针/积木，分「能吸/不能吸」。
🔤 语言点magnet / metal / stick。
✏️ 画+话认字画磁铁和它能吸的东西。
本族 NF 书已全部纳入本周核心。
🧍 第 4 周 · 身体与健康

身体、五感、卫生——最贴近孩子自己的科普。这一周用照镜子、味觉小尝、洗手步骤图，把「我的身体」变成可说的英语+可画的认字素材。

Day 1My BodyNF 科普A · My句式
📖 今日书A74 My Body（Level A，句式：My句式）
🌿 活动唱/指「头肩膝趾」；照镜子指身体部位。
🔤 语言点句型「My ___」(My head / arms / legs)，body 词。
✏️ 画+话认字画自己，标身体部位(头/手/脚)。
Day 2My FaceNF 科普A · My句式
📖 今日书A86 My Face（Level A，句式：My句式）
🌿 活动照镜子认五官；用面团/黏土做一张脸。
🔤 语言点句型「My ___」(My eyes / nose / mouth)，face 词。
✏️ 画+话认字画自画像，标 eyes / nose / mouth。
Day 3This LooksNF 科普A · This句式
📖 今日书A52 This Looks（Level A，句式：This句式）
🌿 活动视觉游戏——看彩色卡/窗外，说「This looks red / big」。
🔤 语言点句型「This looks ___.」，看/颜色词 look / red / blue。
✏️ 画+话认字画一样「看起来___」的东西。
Day 4This TastesNF 科普A · This句式
📖 今日书A41 This Tastes（Level A，句式：This句式）
🌿 活动味觉小尝(苹果/柠檬/盐)，说甜/酸/咸——注意不过敏。
🔤 语言点句型「This tastes ___.」，sweet / sour / salty。
✏️ 画+话认字画一种味道食物，写味道词。
Day 5Clean, Not CleanNF 科普A · Not反义句式
📖 今日书A67 Clean, Not Clean（Level A，句式：Not反义句式）
🌿 活动洗手步骤图(湿/搓/冲/擦)；给玩具「洗澡」区分干净/脏。
🔤 语言点clean / dirty，+ 「Clean, not dirty.」反义词。
✏️ 画+话认字画「干净的手」和「脏的手」。

👥 第 5 周 · 社会与人文

学校、超市、地铁、家——孩子每天穿行其间的「社会地图」。这一周用角色扮演和观察，把地点词和「I / We」句型变成生活用语。

Day 1The SchoolNF 科普aa · 场景认知
📖 今日书AA61 The School（Level aa，句式：场景认知）
🌿 活动角色扮演「上学」——书包/老师/同学；画自己的学校。
🔤 语言点school / teacher / friend / book。
✏️ 画+话认字画学校，标 school。
Day 2The SupermarketNF 科普aa · 场景认知
📖 今日书AA59 The Supermarket（Level aa，句式：场景认知）
🌿 活动超市「购物清单」游戏——画 3 样要买的，找货架；数一数。
🔤 语言点supermarket / food / cart，+ 物品英文名。
✏️ 画+话认字画购物清单(3 样)，标英文名。
Day 3The SubwayNF 科普aa · 场景认知
📖 今日书AA68 The Subway（Level aa，句式：场景认知）
🌿 活动坐地铁/公交观察站名和车厢；用纸条做「车票」。
🔤 语言点subway / train / station / stop。
✏️ 画+话认字画一站地铁，标 station。
Day 4Our Apartment BuildingNF 科普A · 场景认知
📖 今日书A47 Our Apartment Building（Level A，句式：场景认知）
🌿 活动聊「我们住哪里」——楼层/邻居/电梯；用积木搭楼房。
🔤 语言点building / floor / home。
✏️ 画+话认字画自己的家，标 home。
Day 5I Save MoneyNF 科普A · I句式
📖 今日书A73 I Save Money（Level A，句式：I句式）
🌿 活动存钱罐游戏——投币说「I save money」；聊想买什么。
🔤 语言点句型「I ___」(I save / I buy)，money / coin。
✏️ 画+话认字画存钱罐，写「I save」。

🔢 第 6 周 · 思维与创意

颜色、数字、方位、形状、反义词——这些是 RAZ 在低级别里 NF 密度最高的一类(49 本)。这一周把它们全变成「出门就能找」的游戏，词汇最稳扎稳打。

Day 1RedNF 科普aa · 颜色句式
📖 今日书AA26 Red（Level aa，句式：颜色句式）
🌿 活动自然/家里「找红色」——红叶/红花/红车；收集红色物。
🔤 语言点red，+ 颜色词(红/red)。
✏️ 画+话认字画一样红色的东西，标 red。
Day 2OneNF 科普aa · 数字句式
📖 今日书AA29 One（Level aa，句式：数字句式）
🌿 活动数步数/数石头/数豆荚——从 1 数起；用手指比「1」。
🔤 语言点one / two / three… 数字，+ 数数。
✏️ 画+话认字画 1 个苹果，写「One」。
Day 3Jump OverNF 科普aa · 介词反义
📖 今日书AA03 Jump Over（Level aa，句式：介词反义）
🌿 活动身体游戏——jump over / under 枕头；用玩具做「越过/钻过」。
🔤 语言点over / under / in / out 方位词。
✏️ 画+话认字画「跳过」一个东西。
Day 4Shapes in NatureNF 科普A · Shapes句式
📖 今日书A16 Shapes in Nature（Level A，句式：Shapes句式）
🌿 活动自然里找形状——圆石/方砖/三角叶；拓印形状。
🔤 语言点circle / square / triangle，+ 形状词。
✏️ 画+话认字画一个自然里的形状。
Day 5OppositesNF 科普A · 介词反义
📖 今日书A94 Opposites（Level A，句式：介词反义）
🌿 活动反义词动作——big/small、up/down、in/out；照镜子做对比。
🔤 语言点big/little、up/down、hot/cold 反义词对。
✏️ 画+话认字画一对反义词(大/小)。
